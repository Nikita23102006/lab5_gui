## Описание решений

### Средней сложности №8 — диалог выбора файла

Окно демонстрирует все четыре стандартных диалога модуля `tkinter.filedialog`:

- `askopenfilename` — выбор одного файла, показываются его свойства
  (имя, папка, размер, дата изменения) и содержимое;
- `askopenfilenames` — выбор нескольких файлов, выводится список с размерами
  и общий объём;
- `askdirectory` — выбор папки, выводится её содержимое с пометкой подпапок;
- `asksaveasfilename` — сохранение показанного текста в новый файл.

Везде обрабатывается отмена: диалоги возвращают пустую строку или пустой
кортеж, и программа не падает. Файл в чужой кодировке перехватывается
через `UnicodeDecodeError` и не роняет приложение.

### Средней сложности №10 — простейший GUI на PyQt5

Окно на `QWidget` с компоновками `QVBoxLayout` и `QHBoxLayout`:
поле ввода имени, счётчик возраста `QSpinBox`, кнопка приветствия,
блок счётчика нажатий и область вывода результата.

Показана работа сигналов и слотов: `clicked.connect(self.greet)`,
`returnPressed.connect(self.greet)`. Пустое имя перехватывается
и показывается `QMessageBox.warning`.

Отдельно реализовано согласование числительных («19 лет», «21 год»,
«22 года») — метод `_years()`, проверен на 13 значениях.

### Средней сложности №4 — список (Listbox) и выбор элемента

`tk.Listbox` в режиме `EXTENDED` (выбор нескольких элементов с Ctrl и Shift)
с полосой прокрутки. Обрабатываются события `<<ListboxSelect>>` (изменение
выделения) и `<Double-Button-1>` (двойной щелчок переносит значение в поле
ввода).

Реализованы добавление, удаление выделенного, очистка и сортировка.
Удаление идёт в обратном порядке индексов — иначе после первого же удаления
остальные индексы сдвинутся и удалятся не те строки.

### Повышенной сложности №1 — программа «Заметки»

Текстовый редактор с меню «Файл» (Создать, Открыть, Сохранить,
Сохранить как, Выход), панелью кнопок и строкой состояния со счётчиком
строк, слов и символов.

Отслеживание изменений: текущий текст сравнивается с сохранённым,
в заголовке окна появляется звёздочка. При закрытии окна или открытии
другого файла программа спрашивает, сохранять ли изменения
(`askyesnocancel` — три варианта ответа, «Отмена» прерывает действие).

Работают горячие клавиши Ctrl+N, Ctrl+O, Ctrl+S.
Диалоги выбора файла переиспользуются из задания средней сложности №8.

### Повышенной сложности №8 — программа с несколькими окнами

Главное окно управляет тремя типами дочерних:

- **модальное** окно настроек (`grab_set`, `transient`, `wait_window`) —
  блокирует главное окно и возвращает результат через `self.result`;
- **немодальное** окно «О программе» в единственном экземпляре: повторное
  нажатие не плодит окна, а поднимает уже открытое через `lift()`;
- **окно редактора заметок** — переиспользуется класс `NotesApp`
  из задания повышенной сложности №1.

Кнопка «Закрыть все дочерние окна» обходит `winfo_children()`
и закрывает все объекты типа `Toplevel`.

## Связь заданий

Модули переиспользуют друг друга:

- `adv01_notes.py` импортирует фильтры файловых диалогов из `task08_file_dialog.py`;
- `adv08_multiwindow.py` открывает редактор `NotesApp` из `adv01_notes.py`

## Запуск

```bash
pip install -r requirements.txt   # нужно только для задания №10
python3 main.py                   # меню со всеми заданиями
python3 task04_listbox.py         # отдельное задание
```

Требуется Python 3.8 или новее. Tkinter входит в стандартную библиотеку;
в некоторых дистрибутивах Linux его ставят отдельно пакетом `python3-tk`.

## Почему main.py запускает задания отдельными процессами

У Tkinter и PyQt5 собственные циклы обработки событий — `root.mainloop()`
и `app.exec_()`. Запустить два цикла в одном процессе нельзя: второй
не получит управления. Поэтому меню создаёт подпроцесс через
`subprocess.Popen([sys.executable, путь])`. Побочный плюс: задания
можно открыть одновременно и сравнить.
